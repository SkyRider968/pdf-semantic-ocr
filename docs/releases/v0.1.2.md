# 0.1.2 — public USDA demo and Windows compatibility

Run `pdf-semantic-ocr demo --output first-ocr` for actual OCR of a bundled one-page
image-only derivative of the official USDA/HHS December 2020 nutrition brochure.
The HTML preview places the source beside body text, illustration labels and
all measured reference differences. The input is rasterized from a born-digital
original; it is not a physical paper scan.

Protect exact resource bytes from Windows Git newline conversion, write text and
JSON consistently as UTF-8/LF, and read multilingual test output explicitly as
UTF-8. A byte-level regression covers Chinese/English text and JSON. Keep all six
Linux/macOS/Windows × Python 3.10/3.12 CI jobs running to completion. The unpublished
0.1.1 candidate is superseded; its tag is preserved.

Local validation: 47 tests pass, including actual Chinese/English OCR and the USDA
demo. On the development brochure page, complete body accuracy is 99.255% and
completeness 99.379% (1,611 reference characters); illustration labels/page marker
score 100% (68 characters). Residual article, bullet and typography errors remain
visible. These are development/regression results, not a universal OCR benchmark.

The prior clean installed-wheel onboarding took 100.169 seconds including
installation and first model downloads, with cached Python dependency downloads.
See `docs/validation.md` for timing scope and known limits, `docs/demo.md` for
onboarding and `docs/models.md` for model provenance/license qualifications.

Assets include the wheel, source distribution, standalone Codex skill, Chinese
SOP, validation report and SHA-256 checksums. Models download on demand; credentials
and user-provided documents are excluded.
