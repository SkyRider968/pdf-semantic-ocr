# PDF Semantic OCR 0.1.0

First public-ready release of a traceable PDF extraction and audit workflow.

- Unified CLI for native/scanned PDFs, optional trained layout and table engines.
- Separate body/figure/table exports with source page/region records and crops.
- Conservative OTSL table integration, independent OCR matching and replayable repairs.
- Chinese SOP and installable agent skill.
- Original redistributable PDF fixtures, source-declared gold and portable tests.

Tested native extraction, real Chinese/English raster OCR, Apple Vision crosscheck,
DocLayout and local PaddleOCR-VL table recognition. Measured fixture scores and
limitations are in `docs/validation.md`; they do not certify arbitrary PDFs.

Assets: wheel, source distribution, skill ZIP, SOP, validation report and SHA256SUMS.
No private/source-book text, page images, credentials or model weights are included.
