# 0.1.1 — public USDA onboarding demo

Add `pdf-semantic-ocr demo --output first-ocr`: actual OCR of a bundled one-page
image-only derivative of an official USDA/HHS December 2020 nutrition brochure,
with source original/provenance, body versus illustration-label export, complete
body/reference checks, and an HTML source/prediction comparison. The input is
rasterized from a born-digital original; it is not a physical scan.

Add a CPU ONNX DocLayout adapter to the basic `[ocr]` environment, plus a pinned,
SHA-256-verified, atomic model cache. Preserve photographs as crops while excluding
empty figures from text reading order; prefer column gutters and supplement
isolated color badges missed by the model. Preserve numeric page markers in
auxiliary text. English detection uses a 2048-pixel limit and 0.6 box threshold.

Local installed-wheel validation: entire body 99.255% character accuracy / 99.379%
completeness (1,611 reference characters), all visible labels/page marker 100%
(68 characters). First CLI invocation including model downloads: 92.566 seconds;
including cached-dependency installation: 100.169 seconds. One development page,
not a universal benchmark. The preview retains remaining word/glyph differences.
46 local tests pass, including actual Chinese/English OCR and the public demo.
See `docs/validation.md`, `docs/demo.md` and model license metadata qualifications
in `docs/models.md`. Published source and release artifacts are available at
[SkyRider968/pdf-semantic-ocr](https://github.com/SkyRider968/pdf-semantic-ocr).
Remote CI results are recorded separately in the repository’s Actions page.
